# VELNORA HOTEL EMPIRE

Simulador de gestión hotelera para navegador, desarrollado por **VELNORA Studios**.

## Estado actual

La vista del hotel se ha actualizado a un mundo **3D low-poly** con Three.js:
- Cámara isométrica con zoom.
- Isla costera, mar, jardines, caminos y árboles.
- Edificios 3D para habitaciones, suites, restaurante, tienda, piscina y jardín.
- Huéspedes animados que recorren el complejo.
- Selección de parcelas y construcción desde el mapa.
- Gestión de dinero, reputación, huéspedes, empleados y objetivos.
- Guardado automático local en el navegador.

## Cómo jugar

1. Abre el juego desde GitHub Pages.
2. Haz clic en una parcela vacía para abrir el catálogo de construcciones.
3. Compra edificios y amplía la capacidad del hotel.
4. Contrata personal y usa marketing para atraer huéspedes.
5. Cobra la recompensa diaria y completa objetivos.
6. Usa los controles **+**, **−** y **⌖** para ajustar la cámara.

## Tecnología

- HTML, CSS y JavaScript.
- Three.js 0.160.0 cargado desde cdnjs.
- No requiere instalación; necesita conexión a internet para cargar Three.js y las fuentes externas.
